## Accessing the Sub's Computer in a Pool Test

During a pool test, we need to be able to connect to the sub's computer to run the code on the sub's computer to do all the tasks.

For this, there is an ethernet cable on that motherboard of the sub's computer, that extends through a subconn connector on the lid of the sub (the red connector things), that connects to a wifi access point device (like a box/router) on the ground outside the pool. This wifi access point creates a local wifi network, so we can use this local area network (LAN) to VNC into the sub's computer. VNC is like remote controlling another computer, so with VNC you are able to control the sub's screen on your personal computer as if you were directly operating on the sub's computer. Once inside the sub's desktop screen, you can run Nautical-Private and Boops-Boops to run all of the code following the instructions in the "Pool Test Procedure" section.
